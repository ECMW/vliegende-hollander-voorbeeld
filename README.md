# Voorbeeldsite De Vliegende Hollander

Websiteconcept voor particuliere verhuizingen, bedoeld om het ontwerp te bespreken.

Bekijk het voorbeeld: https://ecmw.github.io/vliegende-hollander-voorbeeld/

Dit is geen officiële bedrijfswebsite. Het formulier verstuurt niets, berekent geen prijs en reserveert geen datum. De bestaande bedrijfswebsite blijft ongewijzigd.

De onderzoeksbasis en ontwerpeisen staan in `onderzoek.html`. Dit betreft bronnenonderzoek, geen interviews of tests met klanten. Tarieven, verzekeringsafspraken, bedrijfsfotografie en opvolging moeten vóór inzet als bedrijfswebsite worden bevestigd.

De tijdelijke bedrijfsbeelden zijn afkomstig van de bestaande website: https://verhuisbedrijfdevliegendehollander.nl/img/ (situatie-brug.webp en dienst-handyman.webp). De herkomst en rechten moeten vóór definitief gebruik worden bevestigd. Er wordt geen hergebruiklicentie op deze beelden verleend.

Techniek: statische HTML, CSS en JavaScript, zonder tracking of formulierbackend. Publicatie via GitHub Pages vanaf de hoofdmap van `main`.
